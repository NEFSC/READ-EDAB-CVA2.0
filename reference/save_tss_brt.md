# Calculate True Skill Statistic (TSS) for BRT models

Calculate TSS for BRT k-folds. Used within `eval_brt`. Included with
CVA2.0 package to ensure functionality.

## Usage

``` r
save_tss_brt(truth, predicted)
```

## Source

From Camrin Brawn (WHOI): https://zenodo.org/records/7971532.

## Arguments

- truth:

  observations

- predicted:

  predicted values

## Value

a numeric value
