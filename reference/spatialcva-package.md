# spatialcva: Build a Spatial Climate Vulnerability Assessment

This package provides the tools to build a spatial Climate Vulnerability
Assessment. This includes pulling and formatting the necessary MOM6 and
fisheries data; building and predicting component and ensemble models;
calculating exposure from model predictions; and calculating and
bootstrapping sensitivity from expert scores.
